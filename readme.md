# Amazon Sales Analysis Using Tableau

## Project Overview

This project focuses on analyzing Amazon sales data using Tableau to explore sales performance, product trends, regional patterns, and order cancellations.

Interactive dashboards and visualizations help present the data in a clear and understandable way, supporting data-driven analysis.

## Objectives

- Analyze Amazon sales data to understand overall sales performance.
- Identify best-selling products and product trends.
- Explore sales patterns across different regions.
- Analyze order cancellations and related information.
- Create interactive Tableau dashboards for visual exploration.

## Tools and Technologies

- **Tableau** – Data visualization and dashboard development
- **Microsoft Excel / CSV** – Dataset inspection and preparation
- **Data Analysis** – Exploring sales trends and patterns

## Dataset

The project uses Amazon sales-related datasets in CSV format.

The datasets are used to explore product details, sales information, and order-related patterns. Data preparation and field inspection are performed before creating the visualizations.

> Dataset sources and usage should be acknowledged according to the original dataset license and terms.

## How to Use

1. Download or clone this repository.
2. Open the Tableau workbook (`.twbx`) using Tableau Desktop or Tableau Public, where supported.
3. If Tableau asks for a data source, reconnect it to the appropriate dataset.
4. Open the dashboards and interact with the visualizations using filters and other available controls.
